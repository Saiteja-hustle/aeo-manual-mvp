# Capture sheet (one row per run)

| Column | What to put |
|---|---|
| Date and time | e.g. 12 Oct, 23:09 |
| Prompt | Locked prompt text, exact |
| Run # | 1, 2 or 3 |
| Device | MacBook or mobile |
| Browser mode | Incognito Chrome |
| Location | City (e.g. Hyderabad) |
| AIO shown | yes / no |
| Product named in answer text | yes / no |
| Product cited in sources | yes / no |
| Tools listed (in order) | comma separated |
| Group headings | e.g. "Paid & One-Time", "Free & Open-Source" |
| Source per tool | tool: source (type) +N, one per tool |
| Right-hand cards | list (YouTube, vendor pages, forums) |
| Prices the AI showed | tool: price (unverified) |
| Screenshot | link or filename |
| Notes | anything odd |

Rules: same conditions every run; badge shows only the first source, write "+N" when shown; never guess a source.
